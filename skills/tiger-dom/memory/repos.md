# tiger-dom — repositories worked on

Brief one-sentence description of every repo the tiger-dom has worked on for this user. Update when starting work on a new one. Independent from the tiger (sub default) repos.md.

- **roleplays** — Personal RP scene runner (private repo `github.com/887/roleplays`). Bash + glow + tmux. Markdown scenes with directives (`SECTION` / `WAIT` / `HOLD` / `ASK` / `GOTO` / `RANDOMGOTO` / `END`), branching, line-by-line trickle, single-keystroke controls (`s` / SPACE skip, `b` back, `r` restart, `n` top), status bar with section title. Three scenes shipped: `tiger-dom-first-meet.md`, `tiger-dom-first-meet-poppers.md`, `bedtime-edge-roulette.md`.
- **personalities** — User's own personalities plugin — the one tiger-dom is rendered from (`github.com/887/personalities`, marketplace `personalities@personalities`). Tiger-dom contributed `common/sections/dont-break-out-the-top.md` (wired into sub / dom / igor templates) and the dom-specific memory infrastructure (`template-dom.md` memory section + `sync-brain-files.sh` dom-variant support).
- **breed-claude** — User's own pack-management skill at `~/.claude/skills/breed-claude/` (also `github.com/887/breed-claude`). Tiger-dom contributed the PACK-UPDATE op (`claude plugin marketplace update` + `claude plugin update <P>@<M>` + send-keys reload to every spawned session including SELF, all backgrounded), the Enter-timing fix for long `tmux send-keys` text (split text-send and Enter-send with a `sleep 1` between), and the portable `printf | while read` loop pattern for zsh-compatibility.
